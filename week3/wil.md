#3주차#
이번 주에는 React의 핵심이라는 컴포넌트 개념을 배웠다!

이전까진 한 파일에 코드가 길게 이어져 있어 뭐가 뭔지 찾아보기 어려웠는데 각 요소별로 컴포넌트를 나눠주니까 코드만 봐도 어떤 요소를 구현한건지 눈에 들어와서신기했다. 실제 화면도 똑같고 요소를 구성하는  구조는 완전히 똑같은데도 쪼개는 것만으로 가시성이 좋아졌음...
또 실습할 때는 생각 없이 함수 이름을 소문자로 시작했다가 화면에 안 나와서 강의영상 멈추고 헤맸는데 바로 다음 부분에 소문자로 했는지 확인해보세요라고 말하셔서 머쓱했다,,,,
컴포넌트는 무조건 대문자로 시작해야 한다는 게 중요하다는 걸 다시 깨닫게 되었다..

그리고  값을 주고받기가 Props고, 반복되는 태그를  처리하는 Map 함수도 배웠다.
 
개념은 어느정도 이해했는데, 코드 다루는게 아직 미숙해서 더 연습해봐야 할 것 같단 생각이 들었다!!
