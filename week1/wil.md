
오늘 스터디에선 단순히 코드를 작성하는 것보다 웹 페이지에서 HTML, CSS, JavaScript가 각각 어떤 역할을 하는지 연결해서 이해할 수 있었던 점이 좋았다. 

이번 주차에서는 본격적으로 프론트엔드에 대해 알기 전 웹페이지가 어떻게 동작하는지 간단하게 알아보는 시간을 가졌다. HTML은 웹 페이지의 구조와 관련되어 있고 CSS는 디자인을 담당한다는 것은 알고 있었는데, 별도로 vs code 없이도 실제로 페이지의 내용을 바꾸거나 사용자의 행동에 따라 화면을 변화시킬 수 있다는 점을 새롭게 알게 되었다.특히 DOM이라는 개념을 통해 HTML 요소를 자바에서 찾아서 직접 수정할 수 있다는 것이 생각보다 재미있었다. 또 사용자의 행동을 이벤트라고 하고, 이런 이벤트가 발생했을 때 JavaScript가 실행되도록 만들 수 있다는 것도 새로 알게 되었다.
